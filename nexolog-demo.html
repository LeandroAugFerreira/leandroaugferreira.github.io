02 · O que o código realmente faz

Da interface React ao SQLite

Reserva ≠ baixa física

Em backend/operations.py, pedidos pendentes/processando comprometem o disponível, mas não mudam o saldo físico até a expedição.

Transições controladas

A API aplica estados permitidos e registra eventos. Uma segunda baixa na mesma expedição é evitada por estoque_baixado.

Dados atualizados

O dashboard real consulta pedidos, produtos e movimentações na API; esta página mostra apenas o equivalente didático do fluxo.
