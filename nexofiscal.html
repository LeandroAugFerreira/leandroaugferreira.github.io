Como experimentar no computador

  1. Instale Python 3.13 e Node.js 22.
  2. Baixe o código-fonte e extraia a pasta NexoFiscal.
  3. Abra PowerShell nessa pasta e execute powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\infrastructure\setup-local.ps1 -Portfolio. A primeira instalação precisa de internet.
  4. Execute Iniciar NexoFiscal.cmd e abra http://127.0.0.1:5180.
  5. Escolha Entrar no portfólio. Em Sobre e demonstração → Demonstração, escolha um exemplo e siga a revisão até gerar o documento.

A instalação cria um banco novo com dados fictícios. Gmail e n8n são opcionais; as rotinas também podem executar pela API local. O pacote não contém credenciais, bancos ou dados da instalação do autor.

Acesso público da demonstração: portfolio@nexofiscal.example.com / NexoFiscalDemo@2026. O README explica as demais contas e a configuração opcional do remetente.
