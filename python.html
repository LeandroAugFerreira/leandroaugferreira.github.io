PROJETO PYTHON

Transcrição em Texto

Aplicação web desenvolvida com Python, Flask e Whisper para transformar arquivos de áudio e vídeo em texto, com fila de processamento, cancelamento imediato, tratamento de erros e exportação automática para Microsoft Word.

CONTEXTO

Do áudio ao documento em um único fluxo

O projeto surgiu da necessidade de automatizar a transformação de aulas, gravações e vídeos em documentos de texto organizados. Em vez de executar scripts manualmente, manipular arquivos pelo explorador ou utilizar diferentes ferramentas para cada etapa, a solução concentra todo o processo em uma interface web local.

SOLUÇÃO

Uma aplicação completa de transcrição

A solução utiliza Flask para conectar a interface web ao mecanismo de transcrição Whisper. Os arquivos entram em uma fila dinâmica, são processados individualmente e o resultado é tratado e convertido automaticamente em documentos Word formatados.

🎙️ Transcrição

Reconhecimento de fala utilizando Whisper com foco em conteúdos em português.

⚙️ Fila de processamento

Vários arquivos podem ser adicionados e processados sequencialmente com acompanhamento individual.

📄 Exportação Word

O texto final é transformado em um documento .docx automaticamente formatado.

⏸️ Controle da fila

Pausa entre arquivos, continuação da execução e gerenciamento dos estados da fila.

❌ Cancelamento imediato

O processo do Whisper pode ser interrompido durante uma transcrição sem travar a aplicação.

🛡️ Recuperação de erros

Falhas em um arquivo são tratadas sem necessariamente interromper os demais itens.

DESAFIO TÉCNICO

Cancelamento sem travar o servidor

Durante o desenvolvimento surgiu um desafio: uma transcrição do Whisper é uma operação longa e, se executada diretamente no processo principal, dificulta o cancelamento imediato.

Worker em processo separado

O Whisper passou a funcionar em um processo independente do Flask. Quando o usuário solicita o cancelamento, o backend encerra o worker e possíveis subprocessos associados ao FFmpeg. Em seguida, um novo worker é iniciado, permitindo que a aplicação permaneça disponível para uma nova transcrição.

DEMONSTRAÇÃO

Fluxo de utilização

1. Preparação da fila Arquivos selecionados e aguardando o início do processamento.
2. Processamento Progresso, cronômetros e status atualizados durante a transcrição.
3. Resultado Texto disponível para visualização e documento Word pronto para download.

ROBUSTEZ

Cuidados implementados

  • Prevenção de arquivos duplicados.
  • Tratamento individual de erros na fila.
  • Possibilidade de tentar novamente arquivos que apresentaram erro.
  • Limpeza automática dos uploads temporários.
  • Remoção de arquivos temporários deixados por execuções interrompidas.
  • Proteção contra sobrescrita de documentos Word existentes.
  • Recuperação automática do worker em caso de interrupção.
  • Nova sessão sem necessidade de atualizar a página.

RESULTADO

Da automação em Python para uma aplicação utilizável

O projeto evoluiu de um processo executado diretamente em Python para uma aplicação web completa, capaz de controlar arquivos, processamento, erros, cancelamento e geração de documentos através de uma única interface.
